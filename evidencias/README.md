# Evidencias de validación

`manifest.jsonl` indexa cada solicitud o fallo observado. Respuestas recibidas y errores se guardan bajo `api_responses/` y `errors/`; las rutas son relativas al repositorio y SHA-256 identifica el cuerpo almacenado. No contiene secretos. Conservar esta carpeta como unidad de evidencia; no subirla a repositorios públicos sin revisar términos y datos.

La ejecución actual es una captura puntual, no observación prolongada. Las respuestas HTTP y endpoint oficial no acreditan por sí mismos cobertura de operador, calidad, licencia comercial o permiso de activación.
