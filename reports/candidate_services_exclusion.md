# Decisión de cierre: servicios candidatos excluidos

**Fecha:** 2026-10-25  
**Alcance:** disparador de creatividades de Win ante interrupciones de internet de operadores peruanos.  
**Decisión:** excluir los servicios de esta lista de la solución actual y no volver a probarlos ni integrarlos, salvo que el usuario reabra expresamente la decisión o cambie de forma sustancial el caso de uso.

“Excluido” es una decisión de alcance. No significa que cada servicio haya fallado una prueba. La tabla distingue resultados observados, limitaciones documentales y razones de pertinencia. No se inventan resultados para las opciones que no se probaron.

Su función central es agregar estados de servicios de proveedores; no se demostró que aporte señal local de acceso a internet. No invertir más evaluación en esta opción. ## Regla de no repetición

Estos candidatos quedan **cerrados y excluidos de la solución actual**. No volver a solicitar credenciales, iniciar trials, ejecutar pruebas ni proponer su integración por iniciativa propia. La excepción es una instrucción expresa del usuario para reabrir una opción concreta o nueva evidencia que cambie el alcance. En particular, StatusGator no debe probarse otra vez con la clave temporal recibida y GDELT no debe reintentarse como parte de esta ronda.

## Conclusión

La API de StatusGator fue accesible, pero no dio cobertura peruana atribuible suficiente. GDELT no pudo evaluarse por la respuesta 429 y se excluye por falta de una función directa demostrada para detección local. Los demás servicios se excluyen por requisitos comerciales/de elegibilidad, retiro del producto, falta de una interfaz de datos comprobada o desajuste entre lo que miden y el disparador solicitado. Estas decisiones no equivalen a afirmar que todos fallaron técnicamente.
